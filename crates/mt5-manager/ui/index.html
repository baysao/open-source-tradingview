Bridge manager

Set up this host in five steps, top to bottom. Steps 1 and 2 are one-time; 3 and 4 are what you come back to. Secrets stay in memory for this session only.

    Unregister

    Deletes this bridge from your account using the revoke code shown when it was paired. It cannot read or test any other bridge. This is the last step, not a way to re-pair: to move the bridge to another host, unregister here and pair the new one.

BridgeManager 0.3.0 · revoke codes and tokens are never written to disk or to a log.

Pair this bridge

Mint a code in the hub's Settings (it lives 10 minutes and is single-use). A refused attempt still spends it: mint a fresh code after any error.

Unregister this bridge?

The bridge is deleted from your account. This host keeps running; charts stop receiving its candles. This cannot be undone from here.
