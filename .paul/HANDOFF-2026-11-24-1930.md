## Gotchas found this session (not written anywhere else)

- `hub.html` is themed by `theme.js` writing CSS custom properties, so `verify_states --dark`
  (which only sets `data-theme`) silently re-measures the light theme. Seed
  `localStorage["chartHubTheme"]` in an init script to actually switch themes. L-020.
- Render gates (`verify_states`, `axe_audit`, `measure_render`, `lint_intent`) and the huashu
  scripts (`polish.py`, `design_lint.py`) load `file://` only. On this page the sign-in control is
  injected from `/auth/me`, so they measure an empty page and still report PASS. Use the served
  page via Playwright, or a harness built at gate time. DEBT-016.
- Playwright for a bare repo (no `package.json`): import it absolutely, e.g.
  `import { chromium } from "file:///C:/Users/Dell/.agents/ux-ui-agent-skills/node_modules/playwright/index.mjs"`.
- The test-IdP server needs all three: build `--features test-idp`, a debug profile, and
  `VTV_TEST_IDP=1`; `PUBLIC_ORIGIN=http://127.0.0.1:<port>` is accepted in that build. pgsqlite
  must be up (`~/.local/bin/pgsqlite --database <file> --port <port>`; it now takes `--host`).
- `taskkill //PID <pid>`, with the PID from `netstat -ano`; a running `hub-server.exe` blocks
  `cargo build` from replacing it.
