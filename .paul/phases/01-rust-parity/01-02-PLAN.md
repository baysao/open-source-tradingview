<objective>
## Goal
Build the live half: pure bar building and parsing, `HubState` behind one lock (capacity, 24 sockets per IP, 60 s grace, one builder per timeframe), the upstream session loop with jittered backoff, `FeedHub`/`Subscription`, the `/ws` route speaking today's protocol (D-002), `/api/health`, and end-to-end tests against local fake upstreams.

## Purpose
This is the part that changes behaviour under many viewers: N viewers of one market now cost one upstream connection and one serialization per update. It must stay identical on the wire (G1) and correct under join, leave and grace races.

## Output
The modules in `files_modified`, recorded upstream fixtures, `ws_e2e.rs`, `replay_load.rs`, the `/ws` and `/api/health` contract cases, and `.paul/phases/01-rust-parity/01-02-SUMMARY.md`.
</objective>

## Facts (measured in code, 2026-11-23)
- Browser sends one untyped `{source, symbol, tf}` per socket; a new message replaces the stream; defaults binance, XAUUSD, M1; an unknown tf gets `{"type":"error","msg":"Unknown timeframe X"}` and the socket stays open; a JSON parse error closes the socket; an unknown source becomes Binance (`hub/server.py:686-704`).
- `bar` frames: Binance and Bybit carry `trade_ms`, Deriv does not; `sent` is the uncorrected local clock, `lag_ms` the SNTP-corrected one (`hub/server.py:356-367`, `500-505`, `672-680`).
- Binance and Deriv merge a late trade into the current bar; Bybit drops it (`hub/server.py:356-358`, `472-476`, `678-679`).
- Binance and Bybit throttle to 20 frames per second (50 ms) with no trailing flush; Deriv sends every tick.
- Bybit needs `{"op":"ping"}` every 20 s with the library ping off; Deriv's error reply means market closed and Python waited 60 s.
- `record_tick` granularity: Binance per trade, Bybit per websocket message, Deriv per tick.
- Every `LabFeed.live()` opens its own socket, so an 8-chart layout opens 8 sockets per tab (`hub/lab.js:43-46`).

## Decisions applied
D-002 (protocol, 24 sockets per IP, upstream per `(source, symbol)`, `kind: "capacity"`), D-004 (closed bar published once on roll-over).

## Written defaults (flagged at approval)
- Per-IP limit refusal: HTTP 429 `{"error":"too many chart connections from this address"}` before the upgrade (wire protocol untouched).
- Loopback peers are exempt from the per-IP socket limit while `AUTH_ENABLED=false` (Q-ARCH-2): in local mode every tab is 127.0.0.1.
- At `FEED_MAX_SYMBOLS`, the longest-idle upstream in grace is evicted before refusing (Q-ARCH-3).
- A viewer who joins while the link is down gets the current `status` frame right after `history` (graft from candidate A).
- Every provider reconnects with jittered backoff and sends `status "<Source> reconnecting: <e>"`; Deriv's error reply sends `status "Deriv: <msg>"` and backs off (Python: Binance never reconnected).
- An empty history no longer ends the stream: the builder opens on the first tick (Python: Binance crashed, Bybit stopped).
- `/api/health` lists live upstreams only and keys Binance by the mapped symbol (`binance:BTCUSDT`); no page reads it.
- The single lock is estimated, not measured: the replay load test is an acceptance check (Q-ARCH-5).

## AC-3: Limits
