```rust
// hub-types (this plan: logs.rs)
pub struct LogRow { id: u64, t: i64, src: String, lvl: Level, msg: String }
pub struct SourceInfo { last: i64, expect: Option<u64>, state: String, note: String }
pub struct LogSnapshot { boot: i64, last: u64, now: i64, errors_15m: usize, latest_error: Option<LogRow>,
                         problems: BTreeMap<String, String>, sources: BTreeMap<String, SourceInfo>,
                         #[serde(skip_serializing_if="Option::is_none")] lines: Option<Vec<LogRow>> }
pub struct LogsResponse { #[serde(flatten)] snapshot: LogSnapshot, journal_raw: bool } // always false

// hub-core
pub struct LogRing;  impl LogRing { pub fn push(&mut self, now: i64, line: Line) -> Option<u64>; // throttle (src,msg) within `every`
                                     pub fn snapshot(&self, now: i64, since: u64, brief: bool) -> LogSnapshot;
                                     pub fn replace_problems(&mut self, prefix: &str, desired: BTreeMap<String,String>); }
pub fn redact(msg: &str) -> String;                       // the four patterns of logbus.py, same order
pub struct RingLayer;  // tracing_subscriber::Layer: target -> src, level -> lvl, message + fields -> msg (" k=v"), honours every/persist/alive
pub struct FileSink;   // HUB_LOG_DIR/hub.log, 2 MB x 3, line "ISO lvl src msg", reload last 4,000 lines at boot
pub struct FeedLog;    impl FeedLog { pub fn step(&mut self, input: FeedLogInput) -> FeedLogOutput; } // pure: summary 60 s, silence 120 s, problems, status edges
pub mod net { pub fn rate_limit() -> GovernorLayer; pub fn security_headers() -> ...; pub async fn post_guard(..); }
```

## Facts (measured in code, 2026-11-23)
- Ring 12,000 rows; message cap 2,000 characters after facts and redaction; snapshot `limit=3000`; `brief` omits `lines` but still counts errors; `boot` is process start in seconds and the panel resets on change (`hub/logbus.py:17`, `243-256`; `hub/log_panel.js:64-96`).
- Redaction patterns, in order: `bearer <x>`; `authorization|token|api_key|apikey|secret|password|pwd` followed by `:`, `=` or space and a value; 32+ hex; 40+ of `[A-Za-z0-9+_-]` with optional `=` padding (`hub/logbus.py:30-35`).
- Problem keys the panel relies on: `feed.<k>` for status lights and `feed.<src>:<SYM TF>` per stream; the chip turns red when a key equals the source or starts with `<source>:` (`hub/log_panel.js`).
- Summary line: `60 s: streams=N [SYM:TF,...] updates=U ticks/s=X.X lag_med=Ams lag_p95=Bms bars_served=N reconnects=R errors=E last_data=Ns` (`hub/feedlog.py:111-132`; `bars_served` is one sum).
- `expect()` is never called and `"reader down"` is never set; `HUB_TAIL_FILES` is empty; the stdout `Tee` cap only matters when output is redirected.
- POST guard: only `/api/logs/journal` here (`/api/restart` is not ported, D-001); Origin absent or `http://localhost:<port>` / `http://127.0.0.1:<port>` (plus `PUBLIC_ORIGIN`) else 403 `forbidden origin`; JSON only else 415 `JSON only`; over 300,000 bytes 413 `too large`; the journal endpoint is a no-op returning `{"ok": true}`.
- Start-up lines Python prints: `Clock offset vs time.windows.com: <+N> ms (corrected in lag numbers)`, `TradeX: open http://localhost:8770/hub.html  (data on ws://localhost:8765)`; AGENTS.md also expects `Bybit: <n> charts loaded` and `Deriv: <n> symbols loaded`.
- `lab.js:25` builds `ws://<host>:<LabWsPort>`; `lab.js:95` reads `ws_port`, `mt5`, `arm` (kept, D-003).
- `hub.html` `restartChart()` POSTs `/api/restart` only for broker `arm`; otherwise it reloads the chart (`hub/hub.html:190-201`).

## Decisions applied
D-001 (no `/api/restart`, local mode), D-002 (`lab.js` changes only `wsUrl()`), D-003 (`mt5`/`arm` reads stay in `lab.js`).

## Written defaults (flagged at approval)
- `/api/logs` and `POST /api/logs/journal` stay public in Phase 01 for parity; they move behind admin in Phase 03.
- `HUB_TAIL_FILES` tailing and the stdout `Tee` are not ported; the 60 s summary's `streams=` counts series (`SYM:TF` with at least one viewer), not sockets, and `updates` counts admitted emits per series, not per-viewer sends.
- Rate limit on `/api/*`: 20 requests per second, burst 40, per client IP, 429 with `Retry-After`; loopback is not exempt (an 8-chart cold load is measured in Task 3's human check and the numbers go into the SUMMARY).
- CSP is not set in Phase 01 (inline scripts in four pages); Phase 04 sets it.
