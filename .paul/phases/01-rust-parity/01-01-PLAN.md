## Goal
Create the Cargo workspace (`hub-types`, `hub-core`) and the first half of `hub_core::app`: `Config`, `AppState { cfg, catalog, bars }`, the static file rule, the REST halves of the Deriv, Bybit and Binance providers, `Catalog`, `BarsCache`, and the routes `/api/status`, `/api/symbols`, `/api/instruments`, `/api/bars`. Ship the G1 contract suite (raw JSON key sets and types compared against `python hub/server.py`) so every later plan is measured against it from day one.

## Purpose
G1 ("same charts, new server") is the gate for deleting the Python server (Phase 04). The oracle has to exist before the code it judges; this plan makes it run on the first day, with no binary yet.

## Output
Workspace manifests, the two crates' modules listed in `files_modified`, `tests/contract.rs` with `requests.toml`, and `.paul/phases/01-rust-parity/01-01-SUMMARY.md`.

## Facts (measured in code, 2026-11-23)
- Valid timeframes are exactly M1, M5, M15, M30, H1, H4, D1 (`hub/server.py:49`). An unknown tf on `/api/bars` returns 502 `{"error": "'M2'"}` (KeyError text).
- `/api/bars` caps Binance and Bybit at 1,000 bars (no pagination); Deriv accepts any `limit` via parallel 1,000-candle windows, 5 workers, stops after 4 empty windows; Deriv volume is always 0.0 (`hub/server.py:443-451`, `626-649`, `706-714`).
- `bsym_of` maps XAUUSD to PAXGUSDT, any other `XXXUSD` to `XXXUSDT`, and strips an `EXCHANGE:` prefix (`hub/server.py:51-57`).
- `/api/symbols` order: (arm), bybit, deriv, (mt5), then 9 Binance entries; Binance entries have no `digits`; `lab.js:95-97` warns unless `mt5` and `arm` are "ok" or "off" (D-003).
- Deriv's symbol list never refreshes after its first success; Bybit refreshes every 3,600 s (60 s after a failure) (`hub/server.py:373-400`, `558`).
- `/api/instruments` is cached by total symbol count only (a latent bug); this plan derives it at each catalog refresh instead, which fixes it without a contract change.
- `HEAD` is not overridden in Python, so `HEAD /.env` likely leaks headers; Rust serves GET and HEAD through the same rule.
- `/api/status` 5 s cache existed for the arm network call; with arm gone the response is an O(1) read of the catalog and is not cached.

## Decisions applied
D-001 (local mode, no MT5 or arm code), D-002 (protocol kept, upstream per symbol), D-003 (`mt5` and `arm` stay "off").

## Written defaults (decisions the owner did not make; flagged at approval)
- The contract suite starts the Rust router in-process on `127.0.0.1:0` when `CONTRACT_RS_URL` is unset, because the binary arrives in 01-03; with `CONTRACT_PY_URL` unset it skips with a printed reason (never a silent pass). Rationale: G1 runs from this plan.
- Deriv `/api/bars` `limit` stays uncapped (parity); a cap is a Phase 04 hardening item (Q-ARCH-4).
- Deriv symbols keep Python's "load once" behaviour (parity).
