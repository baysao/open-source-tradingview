<acceptance_criteria>

## AC-1: Startup parity with the Python oracle
Given the env contract
When main.rs starts
Then: no BRIDGE_TOKEN prints the Python line "BRIDGE_TOKEN is required (a random secret; the hub
stores it encrypted)." and exits 1; BRIDGE_BIND/BRIDGE_PORT/MT5_MCP_URL/MT5_MCP_TOKEN/
BRIDGE_STATE_DIR have Python's defaults (127.0.0.1, 8797, http://127.0.0.1:22346/mcp, required,
script dir); an existing .bridge_offset in BRIDGE_STATE_DIR loads as "last measured"; the offset
task measures immediately then every 300 s (15 s until the first success), writing the file on
each accepted measurement; the startup log line reads "native MT5 bridge on <bind>:<port>" (the
Python text, with the binary name in place).

## AC-2: The four routes answer with frozen shapes
Given a served router on port 0 with the in-crate fake terminal
When the routes are driven
Then: missing/wrong bearer answers 401 {"error":"unauthorized"} (a near-miss token `tok` vs
`toke` also 401s: constant-time exact compare); /health carries
{"ok":true,"server":...,"pollers":...,"offset_s":...,"offset_src":...,"measured_at":...} in that
key order; /bars returns a bare array of {time,open,high,low,close,volume}; /wait returns
{"bar":...,"key":...,"tick_ms":...}; unknown path 404 {"error":"not found"}; unknown timeframe
502 {"error":"unknown timeframe M2"}; downstream MCP errors surface as 502 {"error": "<text>"}.

## AC-3: The PollerSet long-poll matches Python's contract
Given two concurrent /wait calls for the same (symbol, tf)
When the first holds after="" and the second after=<current key>
Then only one poller task exists for the pair (the fake's session/call count proves it); the first
returns promptly with the current snapshot; the second blocks until the key changes, returning the
new bar; a waiter on an unchanged key returns by the 20 s deadline (test uses a shrunken deadline);
the poller task stops after 60 s idle (shrunken) and the entry disappears (len() drops).

## AC-4: Errors never wedge a waiter
Given a poller whose terminal call fails
When a waiter awaits
Then the waiter returns the error as 502 {"error": "<text>"} (Python raises RuntimeError from
wait()); subsequent waits may restart the poller.

</acceptance_criteria>
