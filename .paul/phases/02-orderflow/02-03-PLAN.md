```rust
// 200: json_ok(&reply); error: tracing::warn!(target: "server", every = 30,

.route("/api/orderflow/profile", get(..serve(Kind::Profile, ..)))
.route("/api/orderflow/footprint", get(..serve(Kind::Footprint, ..)))
```

## Facts (measured 2026-11-23)
- Python answers 502 `{"error": "<Class>: <msg>"}` for every failure and logs
  `orderflow <kind> <symbol> <tf>: <msg>` at warn with `every=30` (server.py:933, 951, 968).
- The contract suite compares key sets and JSON types per path, has `[allowed]` for map-shaped paths,
  and a case `error` check; it runs in-process or against `CONTRACT_RS_URL`.
- The two servers' rows caches and trade stores hold different histories, so live windows compare by
  shape and status; closed windows older than 3 days touch no trade store and compare by value.
- `/api/*` is rate limited at 20/s, burst 40 per client IP (D-007); the hub's order-flow types poll
  every few seconds per chart.

