<objective>
## Goal
`Db::open(url)` connects to pgsqlite or Postgres, applies the embedded migrations with our own
runner (no `IF NOT EXISTS`, no advisory lock), and the R3 schema is proven on both engines: up, up
again, down, up, constraints and cascades. `Config::from_env` parses the hosted variables and names
every missing one, while `AppState::build` still refuses hosted mode until 03-02.

## Purpose
The pgsqlite limits (D-011, D-014, grounding Addendum) are the largest risk of Phase 03. Closing them
first, before any auth code, means a later failure can only be an auth bug.

## Output
`config.rs` hosted settings, `db.rs`, migration 0001, `tests/common/db.rs` (engine harness),
`tests/db_engines.rs`, the `db` process line, `.env.example`, CI engine jobs, and two measured numbers
(pgsqlite start-up per test, concurrent writers on one file).
</objective>

```rust
// config.rs
pub enum AuthMode { Off, Google(Arc<AuthSettings>) }   // no longer Copy/PartialEq
impl AuthMode { pub fn is_local(&self) -> bool }
pub struct AuthSettings { pub database_url: Secret, pub client_id: String, pub client_secret: Secret,
    pub secret_key: SecretKey, pub admin_emails: Vec<String>, pub idp: IdpEndpoints }
pub struct Secret(String);      // Debug "<redacted>", no Display, expose() pub(crate)
pub struct SecretKey(Vec<u8>);  // base64url, decoded len >= 32
pub struct IdpEndpoints { pub auth_url, pub token_url, pub jwks_url: String, pub issuers: Vec<String> }
pub enum ConfigError { Invalid { key, value }, Missing { keys: Vec<&'static str> }, AuthNotAvailable }
// db.rs
#[derive(Clone)] pub struct Db(PgPool);
pub struct Migration { pub version: i64, pub name: &'static str, pub up: &'static str, pub down: &'static str }
pub const MIGRATIONS: &[Migration];
pub enum DbError { Connect(sqlx::Error), Migration { version, source }, ChecksumChanged { version }, UnknownApplied { version }, Gap { version } }
impl Db { pub async fn open(url: &Secret) -> Result<Db, DbError>; pub(crate) fn pool(&self) -> &PgPool;
          #[cfg(feature = "test-idp")] pub async fn open_with(url, list); #[cfg(feature = "test-idp")] pub async fn migrate_down_all(&self) }
pub fn checksum(sql: &str) -> [u8; 32];          // CRLF -> LF, SHA-256
pub fn plan_migrations<'m>(all: &'m [Migration], applied: &[(i64, Vec<u8>)]) -> Result<Vec<&'m Migration>, DbError>;
pub fn is_unique_violation(e: &sqlx::Error) -> bool;   // 23505, or 42000 + "UNIQUE constraint failed"
fn is_missing_table(e: &sqlx::Error) -> bool;          // 42P01, or "no such table"
pub(crate) const STATEMENTS: &[&str];                   // M1, M2, M4, M5
```

## Facts (measured 2026-11-23 and 2026-11-24, grounding and Addendum)
- pgsqlite is `~/.local/bin/pgsqlite` 0.0.22 (owner's install, `PGSQLITE_BIN` overrides); gaffa is
  `~/.local/bin/gaffa`. No Postgres server listens on this PC (5432 closed): locally the Postgres half
  of every engine test prints SKIPPED unless `VTV_TEST_PG_URL` is set; CI runs it (Postgres 17 service,
  `VTV_TEST_REQUIRE=pgsqlite,postgres` turns SKIPPED into a failure).
- Works through sqlx 0.8: typed binds; single-table SELECT, UPDATE, DELETE, `count(*)`; transactions
  with rollback; `raw_sql` multi-statement bodies; composite PK; FK enforcement and `ON DELETE
  CASCADE`; `ON CONFLICT DO NOTHING` (`rows_affected` 1 then 0); exact `rows_affected` on DELETE.
- Broken: `RETURNING`, joins, scalar subqueries, casts (mistyped columns or protocol errors);
  `CREATE TABLE IF NOT EXISTS` twice ("already exists", 42000); `--in-memory` with a pool (each
  connection its own database); `DEFAULT now()`; `decode()`; `pg_advisory_lock`.
- Unique violation on pgsqlite: SQLSTATE `42000`, message contains `UNIQUE constraint failed`.
- Unmeasured, measured by this plan: `CREATE INDEX` through `raw_sql`; pgsqlite start-up time per
  process; two concurrent write transactions on one file (busy error or wait).
- Callers: `AuthMode` is used in `config.rs` (`bind_addr`, tests) and `lib.rs:85`
  (`cfg.auth == config::AuthMode::Off`); both move to `is_local()`. `ConfigError::AuthNotAvailable`
  is matched only in `config.rs` tests.
- Every new table starts with zero rows: Task 1 inserts a representative row per table by raw SQL in
  the test (NULL in every nullable column: `users.name`, `users.picture`, `sessions.user_agent`) and
  reads it back through sqlx's single-table decode.
- Nullability (R3): `users` id, email, email_verified, created_at, last_login_at NOT NULL; name,
  picture NULL. `identities` all NOT NULL. `sessions` all NOT NULL except user_agent.
  `desktop_auth_codes` all NOT NULL.

## Decisions applied
- D-011 (own runner), D-014 (single-table SQL), D-016 (no health change). Written default for this
  plan: test isolation is the architecture's option (a), one pgsqlite process per test over a fresh
  file in `tempfile::TempDir`; Task 1 measures start-up, and the plan keeps (a) unless the whole
  suite exceeds 3 minutes (then it records the number and proposes (b) as a decision, not silently).
- `AppState::build` keeps refusing hosted mode with `AuthNotAvailable` in this plan (the variant is
  deleted by 03-02 when `AppState::start` exists), so no build of this plan can serve logs publicly
  with auth on.
