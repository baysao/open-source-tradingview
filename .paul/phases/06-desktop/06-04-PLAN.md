<objective>
## Goal
Make the desktop crate continuously verified, ship unsigned installers on a tag, write the two missing
docs pages, and discharge or re-scope every debt row that names phase 06 — including repairing a row whose
check currently passes for the wrong reason.

## Purpose
Three separate jobs that share one property: each is a promise the phase would otherwise make without
evidence.

- **CI.** The crate is not a root workspace member (D-030), so nothing builds it today. A crate nobody
  builds is a crate that is already broken; the first person to try it will be the one publishing a
  release.
- **Docs.** `DEBT-034` says the `/api/me/state` contract lives only in a plan table — a client author
  outside this repo has nothing to read. That is phase 05's debt, and phase 06 is its trigger.
- **Debt.** `DEBT-033`'s check is `grep -c 'D-026' .paul/DECISIONS.md` expecting `1`. `D-026` **already
  exists** as "no IndexedDB mirror in phase 05" (`.paul/DECISIONS.md:155`), so the row self-discharges on an
  unrelated match. The row's own note predicted exactly this class of trap; it just picked an id already
  taken. Measured at resume: `grep -c 'D-026' .paul/DECISIONS.md` → `1`, and the row reads `waiting` only
  because nobody had looked.

## Output
- `.github/workflows/desktop.yml` — the desktop crate's own build/test jobs (Windows + Linux) and the
  unsigned installer build on a tag
- `.github/workflows/ci.yml` — a one-line extension so fmt covers the desktop crate
- `docs/api.md` — the `/api/me/state` contract, written from `crates/hub-core/src/routes/state.rs`'s module

  D-031 (the state cap stays corrective)

## Signing posture, stated once

`Q4` is open: no certificates (`.paul/design/specs/vtradingview.md:104`). Therefore:

- the installer job builds **unsigned** and says so in the release notes;
- `tauri.conf.json` carries **no** `certificateThumbprint`, no `signCommand`, no notarisation keys;
- the job is written so adding certificates later is a secrets-only change (the env names are the ones
  `/signing-tauri-apps` documents: `WINDOWS_CERTIFICATE`, `WINDOWS_CERTIFICATE_PASSWORD`,
  `APPLE_CERTIFICATE`, `APPLE_SIGNING_IDENTITY`, `APPLE_API_*`), each step guarded by
  `if: env.X != ''` so an absent secret is a clean skip, not a red run.
