## Gotchas that live nowhere else (fresh, from this session)

1. **The overlay's heading is `<h2>`, not the mockup's `<h3>`.** The page's only heading is
   `<h1>TradeX</h1>`; axe `heading-order` fails an h3. The mockup's h3 was mock-context.
2. **`.desk-card .steps` needs its own `[hidden]` rule** (`.desk-card .steps[hidden] { display:none }`):
   `display:grid` on the element beats the UA `[hidden]` rule, and the steps otherwise render inside
   the waiting card while every attribute assert reports `hidden=true`.
3. **`deskHide`'s flag parameter is `rerender`.** Named `render` it shadows the render function —
   Cancel then removes the overlay but leaves the busy button and drops focus.
4. **The design-gate receipts are green only on an auth-off base.** With `AUTH_ENABLED=true`, D-019's
   sticky auth slot hit-tests as covering the bar content that scrolls under it (1/4/1 covered
   focusables at 320/768/1280 px on hub.html) — the sticky design itself, not a page defect. The
   receipts convention runs against the auth-off hub; DEBT-035 carries the gate_all.py base note.
5. **obscura refuses loopback URLs** (SSRF guard). The working fallback for 127.0.0.1 served checks is
   the playwright MCP; obscura still cannot drive a native Tauri window (the phase's residual `uat`).
6. **Exchange robustness:** any non-401/400 status maps to the 503 copy; a `startSignIn` rejection
   shows the "app could not open your browser" copy (plan left the string open; it is in auth.js).
7. **Owner decision: do NOT deploy.** The live site stays v0.1.1; the 06-03 page change is verified on
   the test server only. Any deploy is a separate, explicit step.
8. **WebView2 holds the user-data dir after a killed app** → relaunch panics with
   `HRESULT(0x800700AA)`. Kill `msedgewebview2.exe` first. The dev-time `vtradingview` protocol
   registration was removed on purpose; the app re-registers on next launch.
9. **A lesson worth keeping:** the unit checks were green while the render lied twice this session
   (steps visibility, heading level) — the served render-and-look pass caught both. Trust a
   screenshot over an attribute assert for visibility.
