## Gotchas found this session (not written anywhere else)

- **`.env` in this repo sets `AUTH_ENABLED=true` and `PUBLIC_ORIGIN=http://127.0.0.1:8770`.**
  A build WITHOUT `--features test-idp` rejects that origin (https required) and refuses to
  start; `dotenvy` does not override real env vars, so prefix commands with
  `PUBLIC_ORIGIN=... AUTH_ENABLED=false` (or build with `--features test-idp` and set
  `VTV_TEST_IDP=1`).
- **Hosted mode is the wrong mode for a load test.** Loopback is exempt from the per-IP cap
  only when auth is off (`Limits.exempt_loopback`, `per_ip = 24`). In hosted mode a
  single-machine run cannot pass 24 sockets, and my first run hung on exactly that.
- **`/api/health` has no upstream count field.** `feeds` is a map keyed `source:symbol`; count
  its keys. `/api/status` is keyed by source name only.
- Building `hub-server` while an instance runs fails with `rust-lld: Permission denied` on
  Windows: find the PID by its port (`netstat -ano | grep :8770`), `taskkill //PID <pid> //F`.
- The `timeout` command around a node process can leave the child alive; the load script's own
  duration is the real terminator.
- `curl -o nul` on Git Bash creates a 35.7 KB file literally named `nul` (it is not the Windows
  null device). One was created and deleted this session; use `-o /dev/null`.
