## Gotchas (carried forward, all still true)

- **`.env` sets `AUTH_ENABLED=true` and `PUBLIC_ORIGIN=http://127.0.0.1:8770`.** A build without
  `--features test-idp` rejects that origin and refuses to start. Real env vars win over `.env`
  (dotenvy does not override), so prefix local runs:
  `PUBLIC_ORIGIN=http://127.0.0.1:8770 AUTH_ENABLED=false`.
- **Hosted mode breaks single-machine socket tests.** Loopback is exempt from the 24-socket per-IP
  cap only when auth is off. Test websockets in local mode.
- **`/api/health` has no upstream count field.** `feeds` is a map keyed `source:symbol`; count
  its keys. `/api/status` is keyed by source name.
- Rebuilding while `hub-server.exe` runs fails with `rust-lld: Permission denied`. Find the PID
  by its port and `taskkill //PID <pid> //F`.
- `curl -o nul` in Git Bash creates a real 35 KB file named `nul`; use `-o /dev/null`.
- A self-test that greps `$SELF` for a pattern its own line contains can never fail (L-024).
  Scan the body.
- Python on Windows resolves `bash` to WSL's stub; prefer Git Bash's path (L-025).
