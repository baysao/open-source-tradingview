## Gotchas that live nowhere else

1. **The permission id is `allow-start-sign-in`** (hyphens). tauri-build slugifies `_` → `-`.
2. **`window::build(app)` takes no state.** `DesktopState` is `app.manage()`d in `setup`; read it with
   `app.state::<DesktopState>()`.
3. **`start_sign_in` returns in ~34 ms** — it launches the browser on a worker thread. A synchronous
   `open_url` blocked the main thread for 84 s and then failed with `os error 1223`. Nothing may assume
   the tab already exists.
4. **`on_page_load` is builder-only** and lives in `window.rs`. `deep_link()` needs
   `use tauri_plugin_deep_link::DeepLinkExt`.
5. **The event is `vtv:desktop-code` with `detail.code`**, delivered by a Rust-side `eval` — no
   capability, no navigation, so the page's in-memory `desktop_key` survives it (D-029).
6. **The live site is v0.1.1 (`ee3e1fe`)**: `auth.js` has no desktop branch, `sync.js` 404s. The owner
   chose **not to deploy**, so 06-03's page change is verified locally/test server only until a
   deliberate release.
7. **Why the app currently ends on `/hub.html?signin=failed`:** the deployed `auth.js` navigates to
   `/auth/google/start?client=web` *inside the webview*, so `__Host-vtv_oauth` lands in the webview jar;
   the guard then hands Google's URL to the system browser, which has no cookie → `TicketMissing`
   (`crates/hub-core/src/auth/mod.rs:741`). 06-03 fixes the page, not the shell.
8. **WebView2 holds the user-data dir after a killed app** → relaunch panics with
   `HRESULT(0x800700AA)`. Kill `msedgewebview2.exe` first. Drive the window with
   `WEBVIEW2_ADDITIONAL_BROWSER_ARGUMENTS="--remote-debugging-port=922N"` + `Runtime.evaluate`.
9. **The dev protocol registration was removed on purpose** (`reg delete HKCU\Software\Classes\vtradingview`)
   so it does not point at a debug binary. The app re-registers itself on the next launch.
10. **A lesson worth keeping (m4, 06-02):** a mutation can pass because the *test* is vacuous. My
    mid-drain test passed under the broken ordering until it asserted the ordering directly. When a
    mutation survives, suspect the test before concluding the code is fine.
